## Docker Commands
### Build a Docker Image
`docker build -t <image-name> .`: Builds a Docker image using the `Dockerfile` in the current directory.
* `-t`: Assigns a name/tag to the Docker image.
* `<image-name>`: Name you want to give to the image.
* `.`: Uses the current directory as the Docker build context.

### Build an Image with a Version Tag
`docker build -t <image-name>:<tag> .`: Builds a Docker image with a specific version tag.
* `<image-name>`: Name of the image.
* `<tag>`: Version or identifier for the image.
Example:
`docker build -t my-app:1.0.0 .`

### List Docker Images
`docker images`: Lists all Docker images available on the system.

### Run a Container
`docker run <image-name>`: Creates and runs a new container from the specified Docker image.
* `<image-name>`: Name of the image from which the container will be created.

### Run a Container with Environment Variables
`docker run --env-file .env <image-name>`: Creates and runs a container while loading environment variables from the `.env` file.
* `--env-file .env`: Loads environment variables from the specified `.env` file.

### Run a Container with Port Mapping
`docker run -p <host-port>:<container-port> <image-name>`: Creates and runs a container while mapping a host port to a container port.
* `-p`: Maps a host port to a container port.
* `<host-port>`: Port on your computer.
* `<container-port>`: Port exposed by the application inside the container.
Example:
`docker run -p 5000:5000 <image-name>`

### Run a Container in Detached Mode
`docker run -d <image-name>`: Creates and runs a container in the background.
* `-d`: Runs the container in detached mode, allowing you to continue using the terminal.

### Run a Container with Environment Variables, Port Mapping, and Custom Name
`docker run -d --env-file .env -p <host-port>:<container-port> --name <container-name> <image-name>`: Creates and runs a container in the background with environment variables, port mapping, and a custom container name.
* `-d`: Runs the container in detached mode.
* `--env-file .env`: Loads environment variables from the `.env` file.
* `-p`: Maps the host port to the container port.
* `--name`: Assigns a custom name to the container.
* `<container-name>`: Name you want to give to the container.
* `<image-name>`: Image used to create the container.

### List Running Containers
`docker ps`: Lists currently running Docker containers.

### List All Containers
`docker ps -a`: Lists all Docker containers, including stopped containers.
* `-a`: Includes stopped containers in the output.

### View Container Logs
`docker logs <container-name>`: Displays the logs generated by the specified container.

### Follow Container Logs
`docker logs -f <container-name>`: Continuously displays new logs generated by the container.
* `-f`: Follows the container logs in real time.

### Stop a Container
`docker stop <container-name>`: Stops a running container.

### Start a Stopped Container
`docker start <container-name>`: Starts an existing stopped container.

### Restart a Container
`docker restart <container-name>`: Stops and starts the specified container again.

### Remove a Container
`docker rm <container-name>`: Removes a stopped container.

### Force Remove a Container
`docker rm -f <container-name>`: Stops and removes the container immediately.
* `-f`: Forces removal of the container.

### Remove a Docker Image
`docker rmi <image-name>`: Removes the specified Docker image.

### Remove a Specific Image Version
`docker rmi <image-name>:<tag>`: Removes a specific tagged version of a Docker image.

### Inspect a Container
`docker inspect <container-name>`: Displays detailed information about a Docker container, including configuration, networking, mounts, and environment settings.

### Open a Shell Inside a Running Container
`docker exec -it <container-name> bash`: Opens an interactive Bash shell inside a running container.
* `-i`: Keeps standard input open.
* `-t`: Allocates a terminal.
If Bash is not available:
`docker exec -it <container-name> sh`

### Check Docker Disk Usage
`docker system df`: Displays Docker disk usage, including images, containers, volumes, and build cache.

### Remove Unused Docker Resources
`docker system prune`: Removes unused Docker resources such as stopped containers, unused networks, and dangling images.
**Note:** Use this carefully because it can remove resources you may still want.
